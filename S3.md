### What is S3
Amazon "simple" storage service is a highly scannable , secure, durable ocject storage service used for storing and retrieving any amount of data from anywhere. It is widely adopted for data lakes, backups, archives , static website hosting, IoT data storage, and analytic workloads. 

### How does it work?

S3 works with these core concepts:
- Buckets: COntainers for storing objects. Bucket names are globally unique and each bucket resides in a specific AWS region.
- Objects: The actual data stored in S3, along with metadata . Each object is defined by a unique key within a bucket.
- Keys: UNique identifiers for objects in a bucket.
- Versioning: Allows multiple versions of an object to be stored, enabling recovery from accidental deletions or overwrites.
- Stores files of any type and size to enourmous scale.

### Different Storage Classes:

- Standard: Designed for frequently accessed data, offering low latency and high throughput.
- Intelligent-Tiering: Automatically moves data between two access tiers (frequent and infrequent) based on changing access patterns.
- Standard-IA (Infrequent Access): For data that is accessed less frequently but requires rapid access when needed. Lower storage cost compared to Standard, but with retrieval fees.
 And more...


 ### What is an endpoint?

 An endpoint in the context of S3 is a URL that you use to interact with the S3 service. It specifies the location of the resource you want to access or modify. For example, an endpoint for an S3 bucket might look like this: `https://s3.amazonaws.com/bucket-name`.

S3 is good for creating endpoints because of the high availability, cost effectiveness and scalability.
